# Screenshots

Full-resolution captures (1206 × 2622, iPhone 18 Pro, status bar at 9:41) for the landing page and store listings.
Every screen comes in `light/` and `dark/` with the same file name. The data is HogLens' built-in demo mode, with three
fictional projects: Tsara Market, Lumen Docs and Rova Travel.
